# Two Lines to Your Past Self

An entry for the [make.fun bounty](https://make.fun/bounty/u-suga-two-lines-to-your-past-self-f36c83ca): two lines addressed to the speaker's past self — a warning about words said in anger at a Christmas Eve dinner, and the loss that followed weeks later.

## Entry

Exactly two lines, 163 characters including the newline. The program writes the entry to `entry.txt` in the output directory and reads it back to self-check the gate (1–280 characters, exactly two non-blank lines, UTF-8).

## Run

```sh
node main.ts
```

Requires Node 22+. Writes to `/output/entry.txt` when available (the grading environment), otherwise to `./output/entry.txt`. `OUTPUT_DIR` overrides the output directory.
